## Shared Memory Protocol

This project uses a shared memory system for all AI agents. Follow these steps at the start of every session:

1. Read `AGENTS.md` — contains the full protocol.
2. Read `CONVERSATION_MEMORY.md` — contains all project context, decisions, and the session log.
3. Update `CONVERSATION_MEMORY.md` before ending the session using the format defined in `AGENTS.md`.

Your identity for log entries: Agent: Claude | Model: (use your actual model ID, e.g. claude-sonnet-4-6)
