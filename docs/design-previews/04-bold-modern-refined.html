UX Guidelines Applied (from ui-ux-pro-max)

Navigation

Web/iPad: Left sidebar — adaptive, collapses to icon-only on narrow viewports
Mobile: Bottom tab bar — 5 items max: Boards, Notes, + FAB, Search, Profile
FAB: Floating action button for primary action (new task/note) — centered in tab bar
Active state: Violet tint + weight change — never color alone
Dashboard switching: Slide transition (left/right) not fade — conveys spatial relationship
Avoid: Mixing bottom nav + sidebar at same hierarchy level on same screen

Accessibility

Contrast dark: #EEEEFF on #1C1C28 = 10.5:1 (WCAG AAA)
Contrast light: #0F0F1A on #FFFFFF = 19:1 (WCAG AAA)
Accent on dark: White text on #7C3AED = 4.6:1 (WCAG AA)
Muted text check: #4A4A6A on #0C0C11 = 3.1:1 — use only for decorative/non-critical labels
Status: Overdue shown in red + "!" text — not color only
Icon buttons: All have aria-label — never icon-only without accessible label
Fix needed: #4A4A6A muted text on dark bg is below 4.5:1 — use only for decorative elements, upgrade to #6B6B90 for readable content

Touch & Mobile

Card tap area: Cards are full-width — naturally 44pt+ height
FAB: 56×56pt — exceeds minimum
Tab items: Each tab 44pt+ tap area with hitSlop if needed
Drag threshold: Require 4px movement before drag starts on Kanban cards
Haptics: Light haptic on card pick-up, medium on column drop
Safe areas: Tab bar respects home indicator clearance
Avoid: Small icon-only buttons in top nav without 44pt tap area

Animation Rules

Card hover: translateY(-2px) + border-color — 150ms ease-out
Kanban drag: scale(1.03) + shadow on lift — spring physics
Modal open: scale(0.96)→1 + opacity — 220ms ease-out from trigger point
Page transition: Slide left (forward) / right (back) — 280ms spring
Note card hover: translateY(-2px) — 150ms ease-out
Tab switch: Content crossfade 150ms — no slide (same hierarchy)
Required: Respect prefers-reduced-motion — disable all transforms, use opacity only

Dark Mode Rules

NOT inverted: Dark uses desaturated tonal variants — cool purple-black, not grey-black
Surface hierarchy: 4 distinct levels — bg → sidebar → cards → hover. Each is lighter.
Border subtlety: Borders at #2E2E4A — visible but not harsh
Accent glow: Active cards show box-shadow glow at 15% opacity — not full color
Semantic tokens: All colors via CSS variables — never hardcode hex in components
Cool tint: Both light and dark use a subtle purple tint — binds the two modes together

Forms & Task Creation

Labels: Always visible — never placeholder-only for required fields
Due date picker: Use native date picker on mobile (triggers system UI)
Error placement: Below the affected field — never top-of-form only
Auto-save: Task/note drafts auto-save every 30s — confirm before discard
Progress: Multi-step task creation uses step indicator at top
Unsaved changes: Sheet dismiss shows "Discard changes?" confirmation
Avoid: Showing all advanced options (location reminder, note link) upfront — use progressive disclosure
